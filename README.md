# IA'impact — Calculateur pédagogique d'impact environnemental de l'IA

Outil web pour **estimer et visualiser l'impact environnemental d'une session de travail assistée par IA** (énergie, CO₂e, eau de refroidissement), pensé pour la formation.

**➡️ Utiliser l'outil en ligne : https://thobaedulab.github.io/ia-impact-calculateur/**

## À quoi ça sert

On compose une session à partir de tâches courantes (planification, rédaction, tableaux de suivi, etc.) et des outils IA utilisés. Le calculateur estime alors :

- l'énergie consommée (Wh / kWh),
- l'empreinte carbone (g / kg CO₂e),
- l'eau de refroidissement (≈ 1,8 L/kWh),

et propose des **équivalences parlantes** ainsi qu'un **score de session** pour ouvrir la discussion en formation.

## Points pratiques

- **100 % local, aucune donnée envoyée** : tout tourne dans le navigateur. On peut **exporter / importer** une session en fichier `.json`.
- **Aucune installation** : un simple lien à ouvrir. Fonctionne aussi hors-ligne une fois la page chargée.
- **Sources citées** dans l'outil (AIE, ecologits, impactco2, etc.) pour creuser le sujet.
